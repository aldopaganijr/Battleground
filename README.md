
# ⚔️ Battleground

An AI-powered battle game built with Claude Code.

Battleground lets you generate unique fighters, put them head-to-head, and watch AI decide who wins.

This is the final project from my **Claude Code for Beginners: Thrive in the AI Era** course on Zero To Mastery.

## 🎮 What is Battleground?

Battleground is a game we build from scratch throughout the course using Claude Code.

Along the way, we go from a simple idea to a working application, learning how to plan, build, debug, and deploy with AI.

### Features

- **AI-Generated Fighters** — Create unique fighters on the fly.
- **AI Battle Judge** — Let an AI model determine the outcome of each fight.
- **BattleDex** — Keep track of your fighters.
- **Custom UI** — An interactive interface built with Claude Code.
- **AI Integration** — Connect to AI models through their APIs.

## 🚀 Getting Started

Want to explore the finished project?

Clone the repository:

```bash
git clone https://github.com/aldopaganijr/Battleground.git
cd Battleground
```

Follow the project's setup instructions to install dependencies, configure your API keys, and run the app locally.

**Important:** You'll need your own API keys for the AI-powered features. Never commit API keys or `.env` files containing secrets to GitHub.
